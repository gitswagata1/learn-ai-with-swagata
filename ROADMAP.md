# Roadmap

## Vision

The most approachable free introduction to using AI well: clear, practical and open to everyone.

## Milestones

### Now

- [ ] Add short quizzes at the end of each module
- [ ] Save progress locally so learners can resume
- [ ] Accessibility audit (contrast, keyboard, screen readers)

### Next

- [ ] Translations (Hindi, Bengali, Tamil, Telugu)
- [ ] Printable certificate of completion
- [ ] Downloadable prompt library

### Later

- [ ] Cohort mode with a facilitator guide
- [ ] Interactive exercises with a live model
- [ ] Video companions for each module

## Where this can go

| Direction | Idea |
| --------- | ---- |
| **Startup** | AI literacy training for schools and small businesses, with a free core and paid cohort programmes. |
| **Publication** | Measure learning outcomes of a two-hour AI literacy course with pre- and post-assessments. |
